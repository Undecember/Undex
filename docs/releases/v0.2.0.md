# Undex v0.2.0 (preview)

Released November 27, 2026.

Undex now uses pstack for development workflows and includes one command to set up
Graphify and pstack in a Git repository.

## Changes

- The installer adds `pstack@pstack-claude` from `michael-denyer/pstack-claude`.
  It removes the curated Superpowers plugin after pstack is installed and enabled.
- Upgrades back up and retire stock Undex agent profiles and clear matching legacy
  subagent defaults. Existing main-model choices, customized profiles, and
  instructions outside Undex's managed block are preserved.
- `undex-project-setup` replaces `undex-graphify`. It runs
  `graphify extract . --code-only`, registers Graphify MCP in the repository's
  `.codex/config.toml`, and adds a short pstack instruction to its `AGENTS.md`.

## Install or upgrade

Extract the source bundle or check out `v0.2.0`, then run `bash install.sh`. Keep
that source directory because the installed command uses the helper there.
To configure a repository, run `undex-project-setup` from inside it and open it
as trusted in a fresh Codex session.

Run `$pstack:setup-pstack` to choose models and reasoning effort for your Codex
profile. Select `session hook: off` if you want the workflow to apply only to
projects you opt into.

## Verification

The release checks cover 52 automated tests, ShellCheck, and Bash syntax on the
release tree and the extracted source bundle. Temporary-profile smoke tests
verified pstack installation and upgrade through the real Codex CLI. A disposable
Git repository verified code-only Graphify extraction, MCP registration, and
preservation of existing project instructions on rerun.

Full fresh-host provisioning, browser dependencies, new-account authorization,
and live pstack model dispatch were outside this verification. This is a preview
for Ubuntu/Debian-based Linux.
