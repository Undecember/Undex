# Undex v0.1.0

Release date: 2026-10-29.

Undex bundles my Codex tools, preferences, and specialized agent roles into a
repeatable Ubuntu/Linux setup.

## Install

From the extracted source archive:

```bash
cd undex-0.1.0
bash install.sh
```

Keep that directory: the installed `undex-graphify` launcher refers to the helper
inside it. Alternatively, keep a Git checkout and run `bash install.sh` there.

Installation uses official upstream commands and requires internet access. Run as
your normal user; missing system/browser packages can require sudo. Codex and
Context7 authorization remain interactive personal steps.

## Included

- Node LTS through nvm; Codex through npm; uv and Graphify with MCP support.
- RTK initialization, Playwright CLI/global skill, and Chrome provisioning.
- Superpowers and GitHub plugins by default; optional plugin selection.
- Sol/medium preferences and all ten original agent roles.
- Private backups and merges that retain unrelated configuration.
- Version-preserving reruns and explicit `--update` support.
- `undex-graphify` for code indexing and MCP configuration within each repository.
- MIT-licensed setup code and configuration templates.

The approval policy is `never` and sandbox mode is `danger-full-access`, matching
the personal setup this repository reproduces.

## Verification and current limits

- 44 automated tests cover installer flows using temporary homes and command doubles.
- ShellCheck and Bash syntax checks pass.
- Real RTK initialization was run twice in a temporary home, preserving another
  hook without duplicating RTK. Real Graphify indexed a disposable Python repository
  without model credentials and wrote only its project MCP configuration.
- Full fresh-host provisioning, Chrome dependency installation, and account
  authorization still require live validation. Automated simulations do not establish
  these flows work on every supported distribution.
- Ubuntu 24.04.5 LTS was the development environment. Other Ubuntu/Debian-based
  distributions are accepted by preflight but have not been independently validated.
- Context7 setup with a custom `CODEX_HOME` is deliberately declined; configure
  that MCP connection manually in the custom home.
- Plugin availability and model access depend on the account. Some preserved role
  instructions refer to Impeccable, which is not installed by Undex.

See `README.md` for flags, recovery instructions, and personal completion steps.
