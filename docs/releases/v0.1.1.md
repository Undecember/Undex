# Undex v0.1.1 — preview

Release date: 2026-11-18.

This update refreshes model routing while retaining focused Luna and Terra roles
and the existing installer behavior.

## Changes

- Main agent and subagent fallback: `gpt-6.2-sol`, medium reasoning.
- Debugger: `gpt-6.2-sol`, high reasoning.
- Reviewer and UI engineer: `gpt-6.2-sol`, medium reasoning.
- Security reviewer: `gpt-6.2-astra`, high reasoning.
- Browser QA, scoped fixes, and focused test work retain GPT-6.1 Terra; exploration,
  documentation lookup, and triage retain GPT-6 Luna and their reasoning settings.
- Routing guidance defines Astra escalation for unresolved cross-module failures
  and competing architectural constraints, and Sol escalation for complex
  integration-test work. These are agent instructions, not automatic model switching.
- Concurrency remains three. Evaluate changes by total usage, retries, review
  corrections, elapsed time, and verification success per accepted result.

## Install or upgrade

From an extracted source bundle or a retained Git checkout:

```bash
cd undex-0.1.1
bash install.sh
```

Keep the source directory because the installed Graphify launcher refers to it.
Rerunning the installer applies the updated preferences and role definitions with
private backups and structural configuration merges. A new Codex session is needed
to load them. Editing this source bundle alone does not update an existing Codex
home. Models require access on the signed-in account; Undex does not substitute
unavailable models. Existing non-interactive and no-login options remain available.

The installer retains approval policy `never` and sandbox mode `danger-full-access`.

## Verification and current limits

- The release checks cover the 44-test automated suite, ShellCheck, Bash syntax,
  and whitespace validation on the release tree and extracted source archive.
- Tests use temporary homes and external-command doubles. They verify configuration
  installation, preservation, reruns, and failure handling; they do not measure the
  new models' quality, actual inference usage, or live model execution.
- Full fresh-host provisioning, browser dependency installation, and new-account
  authorization remain unverified. This release is a preview for that reason.
- Ubuntu/Debian-based Linux remains the supported platform family; custom
  `CODEX_HOME` Context7 setup remains deliberately declined.
- Some role instructions reference Impeccable, which Undex does not install.

## Release assets

- `undex-0.1.1.tar.gz`: source bundle with installer, configuration, documentation,
  license, lockfile, and tests.
- `SHA256SUMS`: checksum for that exact archive.

The source archive is built from the annotated `v0.1.1` tag. The checksum applies
to that exact archive; earlier candidate archives have different checksums.

```bash
sha256sum -c SHA256SUMS
tar -xzf undex-0.1.1.tar.gz
```
